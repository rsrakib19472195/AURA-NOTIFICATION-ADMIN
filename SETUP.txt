FILES
- index.html = Admin Panel
- login.html = Admin Login
- notification.html = Push Notification page
- firebase.js = Firebase + OneSignal client setup
- server.js = Render server + Firebase Admin watcher + OneSignal push
- site-control.js = maintenance/app-update control
- package.json = Render dependencies

RENDER ENVIRONMENT VARIABLES (server-side)
1. ONESIGNAL_REST_API_KEY = your OneSignal REST API key
2. ADMIN_EMAIL = teamgamechangerofficial@gmail.com
3. ADMIN_ONESIGNAL_EXTERNAL_ID = optional. If omitted, server resolves the admin Firebase UID from ADMIN_EMAIL.
4. FIREBASE_SERVICE_ACCOUNT_JSON = recommended: complete Firebase Admin service-account JSON
   OR set:
   FIREBASE_PROJECT_ID
   FIREBASE_CLIENT_EMAIL
   FIREBASE_PRIVATE_KEY

IMPORTANT:
- Never put the OneSignal REST API key inside firebase.js or frontend HTML.
- The Firebase Admin service-account private key is also server-only.
- OneSignal App ID may remain in frontend.

RENDER
Build Command:
npm install

Start Command:
npm start

The server starts the Firebase Admin Firestore listeners automatically.
It watches:
- deposits
- transactions (legacy deposit compatibility)
- withdraws

For every NEW pending request it sends a push notification to the Admin's OneSignal external_id.
It also writes an adminNotifications document and prevents duplicate pushes with adminPushSent.

ADMIN LOGIN
Main URL opens index.html. If no Firebase session exists, it opens login.html.
The login is allowed only for ADMIN_EMAIL.
After login the Admin UID is linked to OneSignal.

FIRESTORE DATA EXPECTED
Deposit requests:
deposits/{requestId} with status: "pending", amount and user information.
Legacy deposits in transactions are also detected.

Withdraw requests:
withdraws/{requestId} with status: "pending", amount and user information.

If a request was created before the Render server started, the server performs a short catch-up scan for recent pending requests.

DEPLOY
1. Upload all files to GitHub.
2. Make sure admin.html is named index.html.
3. Deploy the latest commit on Render.
4. Check:
   /health
The response should show firebaseAdmin:true and onesignalConfigured:true.
5. Log into Admin using the configured ADMIN_EMAIL.
6. Keep OneSignal notification permission enabled on the Admin device.

If /health says firebaseAdmin:false, Firebase Admin credentials are missing/invalid on Render.
If onesignalConfigured:false, ONESIGNAL_REST_API_KEY is missing.
